# Contributing

Public contributions are limited to corrections and improvements to the
documentation in this repository.

Do not submit source code, binaries, archives, game assets, private project
records, personal data, unpublished permission correspondence, or material you
do not have the right to share. A documentation contribution must be suitable
for publication under the license in [LICENSE](LICENSE).

Active source development is private, and a public documentation contribution
does not grant access to internal repositories or imply acceptance into a future
release.
