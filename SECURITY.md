# Security

This public repository contains documentation only. It does not provide an
installer, executable, update feed, package, or public source tree.

Report a suspected security issue privately to
studio@ottergamestudio.com. Do not include credentials, private keys, personal
data, unpublished permission correspondence, or exploit details in a public
issue.

There is currently no public release to download or verify. Files offered
elsewhere as a Between Emissions installer, modpack, update, or signed package
should not be treated as official based on this repository.
