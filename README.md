# Between Emissions

Between Emissions is a work-in-progress project with two separate product lines:

- a modular project for S.T.A.L.K.E.R. Anomaly; and
- a separate overhaul project for S.T.A.L.K.E.R. 2.

This repository is the official public information site for the project. Active
source development is private. This repository does not contain manager source,
module source, tests, packaging, build evidence, game assets, or private rights
records.

## Current public status

- There is no public installer or modpack download.
- There is no signed installer.
- There is no production update feed.
- No gameplay acceptance or release date is claimed.
- Original-module source remains private unless it is deliberately approved for
  a future release.
- Third-party redistribution depends on the applicable rights and permissions.

Development source, prototypes, and internal validation do not make a public
release. An official public release, if one is approved later, will be announced
explicitly in this repository.
